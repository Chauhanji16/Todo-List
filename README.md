 To-Do Application
A simple and user-friendly To-Do Application that helps users manage their daily tasks efficiently. Users can add new tasks, view their task lists, mark tasks as completed, and delete tasks when they are no longer needed.

 Features
1 Add new tasks
2 View all tasks
3 Mark tasks as completed
4 Delete tasks
5 Simple and user-friendly interface
6 Responsive design for different screen sizes

 Purpose
The main purpose of this project is to improve productivity by organizing daily tasks in one place. It also demonstrates practical skills in application development, user interface design, and CRUD operations.
